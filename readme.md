# Jasin Express📦
A **Parcel Management System** developed as part of a team coursework project. It allows user to manage parcel information efficiently with basic CRUD functionalities.

## 🛠️ Tech Stack
- Language: Java
- Database: MySQL (phpMyAdmin)
- IDE: Eclipse

## 💡 Features
- Add and manage parcel delivery records
- Search parcels by tracking number
- Edit parcel details
- Delete parcel entries
- View all parcel statuses
