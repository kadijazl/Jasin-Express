# Jasin Express📦
Jasin Express is a full-stack Parcel Management System developed as a group coursework project. Built using Java, it allows users to manage couriers, parcels, deliveries, transactions, and staff efficiently. The backend uses MySQL for data storage, and the system follows a clear MVC architecture.

## 🚀 Features
- Parcel Module: Add, list, update, and delete parcels
- Delivery Module: Manage delivery records and statuses
- Staff Module: Manage staff details and roles
- Courier Module: Handle courier company information
- Transaction Module: Record and manage parcel transaction histories

## 🛠️ Technologies Used
- Language:	Java
- Backend:	Java Servlets, JSP
- Frontend:	HTML, CSS, Javascript
- Database: MySQL (phpMyAdmin)
- IDE:	Eclipse
